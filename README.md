# Prova de Banco de Dados

Prova prática utilizando **SQL** para manipulação e consulta de dados em uma tabela de livros.

## Conteúdo

A atividade inclui diferentes operações de banco de dados:

- Inserção de registros (INSERT)
- Atualização de dados (UPDATE)
- Exclusão de registros (DELETE)
- Consultas de dados (SELECT)
- Ordenação de resultados
- Agrupamento de dados com GROUP BY
- Cálculo de média com funções agregadas
- Filtros utilizando WHERE, LIKE e BETWEEN

## Tecnologias utilizadas

- SQL
- Banco de Dados Relacional
